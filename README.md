# Gymso Fitness – Gym Website

A responsive gym and fitness center website created as a class project using HTML and CSS.

## Features

- Gymso Fitness landing page
- Navigation and social media icons
- Hero section with call-to-action buttons
- Membership offer and working hours
- Trainer/team section
- Training classes with pricing
- Weekly workout timetable
- Contact form
- Google Maps location embed
- Responsive mobile layout

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Media Queries
- Font Awesome
- Google Maps Embed

## How to Run

Open `index.html` in a browser.

For development, use VS Code with Live Server.

This is a static front-end project and can be deployed directly from the `main` branch using GitHub Pages.
